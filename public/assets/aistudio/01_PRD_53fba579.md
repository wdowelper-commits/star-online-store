# 01_PRD.md — Product Requirements Document
## Project: Zenvo — Multi-Vendor E-Commerce Marketplace

---

## 1. Purpose & Goals

Zenvo ek **multi-vendor e-commerce marketplace** hai jahan multiple sellers apne products list kar sakte hain aur customers unhe browse, wishlist, aur Cash on Delivery (COD) ke zariye order kar sakte hain. Platform ka maqsad Pakistan/India ke local sellers ko ek organized online marketplace dena hai jahan admin sab kuch control kar sake.

**Primary Goals:**
- Sellers ke liye: Easy product listing with image upload
- Customers ke liye: Seamless shopping experience with tracking
- Admin ke liye: Full control — products, orders, users, coupons, inventory

---

## 2. Target Users

| Role | Description |
|------|-------------|
| **Super Admin** | Platform ka owner. Har cheez manage kar sakta hai — sellers, products, orders, users, coupons, categories |

## 4. Core Features

### 4.1 Authentication
- Email + Password signup/login
- Google OAuth login
- Email verification on signup
- Password reset via email
- Role-based redirect after login (admin → /admin, seller → /seller, customer → /account)

### 4.2 Customer Features
- **Homepage:** Hero banner, featured categories, featured products, trending products
- **Browse & Search:** Filter by category, price range, rating, in-stock; keyword search
- **Product Page:** Images gallery, description, price, seller info, stock status, add to cart, wishlist toggle
- **Cart:** Add/remove/quantity change, coupon code apply, COD total summary
- **Checkout:** Shipping address form, COD confirmation
- **Order Tracking:** Status timeline (Placed → Confirmed → Shipped → Delivered / Cancelled)
- **Account:** Profile, address book, order history, wishlist
- **Wishlist:** Save products, move to cart

### 4.3 Seller Features
- **Seller Registration:** Apply to become a seller (admin approval required)
- **Seller Dashboard:** Sales summary, recent orders, low stock alerts
- **Product Management:** Add product (title, description, category, price, stock, images upload), edit, delete, toggle active/inactive
- **Order Management:** View orders for own products, update fulfillment status (Confirmed → Shipped)
- **Inventory:** Stock count per product, low stock notification (threshold configurable)
- **Profile:** Store name, logo, bio, contact info

### 4.4 Admin Features
- **Dashboard Overview:** Total revenue (COD), total orders, total users, total sellers, total products, recent activity
- **Product Management:** View all products across all sellers, approve/reject/suspend products, edit any product
- **Order Management:** View all orders, update any order status (Placed → Confirmed → Shipped → Delivered → Cancelled), filter by status/date
- **User Management:** View all customers, suspend/activate accounts, see order history per user
- **Seller Management:** Approve/reject seller applications, suspend/reactivate sellers, view seller performance
- **Category Management:** Add/edit/delete categories and subcategories
- **Coupon Management:** Create discount coupons (percentage or fixed amount), set expiry, usage limit, minimum order value
- **Inventory Alerts:** See all low stock products across all sellers
- **Image Upload:** Products ke saath multiple images upload (Supabase Storage)

### 4.5 Coupon System
- Coupon code (alphanumeric)
- Discount type: Percentage (%) or Fixed Amount (₹/PKR)
- Minimum order value
- Expiry date
- Max usage count (total)
- Per-user usage limit
- Active/inactive toggle

### 4.6 Image Upload
- Product images Supabase Storage mein store hongi
- Multiple images per product (up to 5)
- First image = thumbnail
- Admin aur Seller dono upload kar sakte hain
- Seller logo bhi upload ho sakti hai

## 5. Business Rules

1. Seller register karne ke baad **admin approval** zaroori hai — tab tak seller products add nahi kar sakta
2. Products **admin approval** ke baad hi publicly visible hongi (seller ke liye optional setting)
3. COD orders mein payment method sirf "Cash on Delivery" — no online payment gateway
4. Coupon ek order mein sirf ek baar apply hoga
5. Stock 0 hone par product automatically "Out of Stock" label show karega, cart mein add nahi hoga
6. Low stock threshold default = 5 units (admin/seller configurable per product)
7. Order cancel sirf "Placed" ya "Confirmed" status tak ho sakta hai
8. Seller sirf apne products aur orders manage kar sakta hai — doosre seller ka data access nahi
9. Admin ke paas platform-wide full access hai
10. Guest browse kar sakta hai lekin cart ya wishlist ke liye login zaroori hai

---

## 6. Functional Requirements

- FR-01: User email + Google se sign up/in kar sake
- FR-02: Seller apna profile + products manage kar sake
- FR-03: Customer products browse, search, filter kar sake
- FR-04: Customer cart mein products add kare, coupon apply kare, COD order place kare
- FR-05: Customer apna order track kar sake (status timeline)
- FR-06: Admin sab orders ka status update kare
- FR-07: Admin users aur sellers manage kare
- FR-08: Admin categories aur coupons manage kare
- FR-09: Product images Supabase Storage mein upload/retrieve hon
- FR-10: Low stock alerts seller aur admin dashboard par dikhen

---

## 7. Non-Functional Requirements

- **Performance:** Page load < 3 seconds on 4G
- **Responsiveness:** Mobile-first, works on 320px+ screens
- **Security:** RLS on all Supabase tables, no secrets in frontend
- **Scalability:** Supabase PostgreSQL handles growth
- **Accessibility:** Keyboard nav, ARIA labels on key elements
- **SEO:** Meta titles/descriptions on product pages

---

## 8. Scope & Exclusions

**In Scope:**
- Multi-vendor marketplace (sellers + admin + customers)
- COD only
- Email + Google auth
- Product image upload via Supabase Storage
- Admin full panel
- Seller dashboard
- Customer shopping flow + order tracking
- Coupon system

**Out of Scope (v1):**
- Online payment gateway (Razorpay, Stripe) — future phase
- Product reviews/ratings — future phase
- Live chat / messaging — future phase
- Mobile app — future phase
- AI recommendations — future phase
- Multi-language support — future phase
